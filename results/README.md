# Results

Collected benchmark evidence — generated by runs, gitignored, never
hand-edited.

results/<domain>/<plan>/case-NNNN/    one gated trial (receipt + result)
results/<domain>/<plan>/SUMMARY.json  all trials + the frozen plan
results/<domain>/<plan>/metrics-summary.csv   medians per (variant, C)
results/STATE.json                    checkpoint (make checkpoint)

Re-runs move old directories to `<plan>-partial-<timestamp>/` instead
of overwriting. Post-process with `make summarize / validate / report`.
